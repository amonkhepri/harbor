# P345-001: ReflectiveMatrixHomeserverDiscoveryClient/ReflectiveMatrixMessageSnapshotClient
# resolve most SDK types (ClientBuilder, Client, Room, HomeserverLoginDetails, etc.) purely
# by Class.forName()/getMethod() string lookups, never by a static type reference, so R8
# shrinking removes them with no keep rule. No-op when the flag is off and the dependency is
# not resolved, matching the existing org.drinkless.tdlib.** keep rule's pattern.
-keep,includedescriptorclasses class org.matrix.rustcomponents.sdk.** { *; }

# P351-001: org.matrix.rustcomponents:sdk-android's UniFFI-generated bridge code (top-level
# uniffi.** packages, not covered by the org.matrix.rustcomponents.sdk.** rule above) declares
# JNA com.sun.jna.Structure/Callback subclasses whose fields are populated by JNA's own runtime
# reflection rather than direct bytecode reads. R8 shrinking can drop such "unreferenced" fields
# even with obfuscation disabled, corrupting the native marshaling layer. Neither the sdk-android
# aar nor the jna aar ships its own consumer ProGuard/R8 rules (both proguard.txt entries are
# empty and no META-INF/proguard rules are embedded), so this app must supply both. No-op when
# the flag is off and neither dependency is resolved.
#
# The com.sun.jna.** keep below reaches com.sun.jna.Native's optional AWT integration
# (Native$AWT, and AWT-typed members on Native itself), which references java.awt.Component,
# java.awt.GraphicsEnvironment, java.awt.HeadlessException, and java.awt.Window. Android ships
# no java.awt package, so R8 fails the build resolving those references even though this
# integration is desktop-only and unreachable from the Matrix connector's native marshaling
# path. Silence just those four evidenced types instead of the whole java.awt.** package, since
# JNA's own reflection still needs every other com.sun.jna.** member kept.
-dontwarn java.awt.Component
-dontwarn java.awt.GraphicsEnvironment
-dontwarn java.awt.HeadlessException
-dontwarn java.awt.Window
-keep,includedescriptorclasses class uniffi.** { *; }
-keep class com.sun.jna.** { *; }
-keepclassmembers class * extends com.sun.jna.Structure { *; }
-keepclassmembers class * implements com.sun.jna.Callback { *; }
